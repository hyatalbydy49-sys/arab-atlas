# Arab Atlas — أطلس عربي حي

Live Arabic world map. Flights, ships, cameras and earthquakes on one map. Free for everyone. No account needed.

خريطة عالم عربية حية. طائرات وسفن وكاميرات وزلازل على خريطة واحدة. مجانية للجميع. بلا حساب.

## Live layers — الطبقات الحية

- Flights (ADS-B) via adsb.lol — طائرات مباشرة
- Earthquakes via USGS — زلازل مباشرة
- Events via NASA EONET — حرائق وعواصف وبراكين
- ISS live position — محطة الفضاء الدولية

## Demo layers — طبقات عرض

Straits, airports, ports, dams and monitoring theatres with real locations. Live AIS and official camera gateways are the next step.

المضائق والمطارات والموانئ والسدود ومسارح المراقبة بمواقع حقيقية. ربط AIS والبوابات الرسمية هو الخطوة التالية.

## Tech — التقنية

- MapLibre GL JS 5 with globe projection
- CARTO Dark Matter tiles
- Esri satellite imagery
- Arabic RTL text plugin

## Run it — التشغيل

Open `index.html` in any browser. No build step. No server needed.

افتح ملف `index.html` بأي متصفح. بلا بناء وبلا سيرفر.
